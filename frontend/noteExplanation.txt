# 2. CREATE — `chatApi.js`

### What changed?

We created a new file:

```text
frontend/src/api/chatApi.js
```

### Why?

Previously, Axios/API communication was inside `App.jsx`.

Now:

```text
App.jsx
   ↓
chatApi.js
   ↓
Backend
```

### Changed code

```js
import axios from "axios";

const API = axios.create({
  baseURL: "http://localhost:3777/api",
});

export const getConversations = async () => {
  const response = await API.get("/chat/conversations");
  return response.data;
};

export const sendMessage = async (question) => {
  const response = await API.post("/chat/conversations", {
    question,
  });

  return response.data;
};
```

### Simple idea

`chatApi.js` is the **messenger** between React and the backend.

# 3. REPLACE — `App.jsx`

### What changed?

Axios code was removed from `App.jsx`.

Instead:

```js
import {
  getConversations,
  sendMessage,
} from "./api/chatApi";
```

### Important changed part

```js
const result = await getConversations();
```

and:

```js
const result = await sendMessage(question);
```

### Why?

`App.jsx` should mainly control the **frontend state and components**.

```text
App.jsx
 ├── Manage messages
 ├── Manage loading
 ├── Send question
 └── Display components
```

It should not contain all the API communication code.

# 6. REPLACE — `backend/index.js`

This is the **most important backend change**.

### Added:

```js
const cors = require("cors");
```

and:

```js
app.use(
  cors({
    origin: "http://localhost:5173",
  })
);
```

### Why?

Your frontend and backend use different ports:

```text
Frontend
localhost:5173

       ↓

Backend
localhost:3777
```

The browser can block this communication because they are different origins.

CORS says:

> "Frontend on port 5173 is allowed to communicate with me."

So:

```text
React :5173
    ↓
 CORS permission
    ↓
Backend :3777
```

# 7. REPLACE — `main.route.js`

### Code

```js
const express = require("express");

const chatRouter =
  require("../api/chat/chat.route");

const mainRouter = express.Router();

mainRouter.use(
  "/chat",
  chatRouter
);

module.exports = mainRouter;
```

### Why?

It connects `/api` to `/chat`.

Because `index.js` has:

```js
app.use("/api", mainRouter);
```

and `main.route.js` has:

```js
mainRouter.use("/chat", chatRouter);
```

the URL becomes:

```text
/api/chat
```

# 8. REPLACE — `chat.route.js`

### Code

```js
const express = require("express");

const {
  createConversationController,
  getConversationController,
} = require("./controller/chat.controller");

const chatRouter = express.Router();

chatRouter.get(
  "/conversations",
  getConversationController
);

chatRouter.post(
  "/conversations",
  createConversationController
);

module.exports = chatRouter;
```

### Why?

This tells Express:

```text
GET /conversations
        ↓
getConversationController
```

and:

```text
POST /conversations
        ↓
createConversationController
```

Because of the previous `/api/chat`:

```text
GET  /api/chat/conversations
POST /api/chat/conversations
```

# 10. Why Each File Was Changed

| File              | What it does           | Why changed                      |
| ----------------- | ---------------------- | -------------------------------- |
| `chatApi.js`      | Talks to backend       | **NEW** API separation           |
| `App.jsx`         | Manages frontend       | Uses `chatApi.js`                |
| `MessageList.jsx` | Displays messages      | Correct message/scroll flow      |
| `ChatMessage.jsx` | Displays one message   | Fix JSX + preserve Markdown/code |
| `index.js`        | Starts backend         | Add **CORS**                     |
| `main.route.js`   | Connects `/api/chat`   | Connect routing cleanly          |
| `chat.route.js`   | Defines chat endpoints | Connect URLs to controllers      |

### The main lesson

You are basically separating the project into **jobs**:

```text
App.jsx        → Frontend manager
chatApi.js     → API messenger
index.js       → Backend entrance
main.route.js  → Main routing
chat.route.js  → Chat routing
Controller     → Receives request
Service        → Does the work
MySQL          → Stores data
Gemini         → Generates AI answer
```

So the changes are not random. They make each part have **one clear responsibility**.
